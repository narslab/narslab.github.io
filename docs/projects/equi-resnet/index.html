Equitable Resilience in Multilayer Transportation Infrastructure Networks

This repository contains the data and code used in the article Resilience in multilayer transportation infrastructure networks: a review and conceptual framework for equity-based assessment (Sustainable and Resilient Infrastructure, 2024).

The study provides a comprehensive review of resilience concepts and metrics, highlights research gaps in multilayer transportation systems, and introduces a conceptual framework that integrates equity-based measures into resilience assessment. Using the Pioneer Valley region in Massachusetts as a case study, the framework demonstrates how incorporating socioeconomic and demographic variables can guide more inclusive and equitable infrastructure planning.

Data

  • Network data: Extracted using OSMnx (roads, intersections, bridges, transit stops, buildings).
  • Socioeconomic data: U.S. Census Bureau American Community Survey (population density, income, education).
  • Outputs: Adjacency matrices, resilience metric histograms, and equity-weighted spatial plots.

Results

  • Computed resilience metrics (degree, overlapping degree, PageRank).
  • Equity-weighted resilience metrics and composite equitable resilience index.
  • Identification of critical nodes for targeted investment to enhance resilience and equity.
